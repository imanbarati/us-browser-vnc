# GitHub Codespaces noVNC (temporary)

Codespaces gives you a Linux container with a US GitHub datacenter IP. It is
**ephemeral** — the browser session disappears when the codespace stops. GitHub
does not allow using Codespaces as a general-purpose VPN/proxy or for bypassing
service restrictions. Use it only for legitimate development/testing.

Create a codespace from this repo in GitHub; the devcontainer installs noVNC and
forwards port 6080. Open the forwarded port in your browser and connect with
the password printed in the terminal.

No account automation or credential storage is included.
